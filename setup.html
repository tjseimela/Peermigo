LAUNCH GUIDE

Go live when you’re ready.

See what is working in demo mode and exactly what you need to activate the shared student platform.

YOUR CURRENT MODE

Local demo preview

Sample profiles, test groups, local-only messaging and saved profiles let you try the design safely. Nothing is shared between students.

01

Supabase project provided ✓

This website is configured for your existing Supabase project. Keep Row Level Security enabled and complete the SQL and authentication steps below.

02

Run the database SQL

Open supabase/schema.sql from your downloaded website folder, then run it once in Supabase → SQL Editor. It creates profiles, messages, groups, sessions, notifications and access policies.

03

Project keys added ✓

Your public Supabase Project URL and publishable key are already in config.js. No further key entry is needed. Never upload service-role or secret keys.

04

Enable email authentication

In Supabase → Authentication, enable email sign-in and configure your Site URL and redirect URLs for your Netlify domain. Use email confirmation for real accounts. Test with two different emails and browsers.

05

Deploy and test responsibly

Upload the complete folder to Netlify. Before inviting students, provide a privacy policy, community rules and a real moderation contact. This beta is intended for 18+ users. Review South Africa’s POPIA obligations and obtain appropriate advice.

♧
Verification is not automatic

Institution names are self-reported. An administrator reviews documentation out of band and sets is_verified in Supabase. Never treat simply entering a school as proof of enrolment.
