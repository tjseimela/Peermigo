# Peer Match 🎓

**Peer Match** is a student collaboration platform designed to help students connect, find compatible study partners, and succeed academically together.

The platform offers student matching, private messaging, study groups, session scheduling, and shared notes, making it easier for students to collaborate and learn from one another.
